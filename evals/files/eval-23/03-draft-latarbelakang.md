# Latar Belakang (draft v1)
UMKM kopi di Makassar berkembang pesat. Kedai Kopi Senja mencatat stok secara manual sehingga terjadi selisih stok sekitar 5 kg per bulan. Metode Economic Order Quantity (EOQ) dapat digunakan untuk menentukan jumlah pesanan optimal. Oleh karena itu dibutuhkan sistem informasi persediaan berbasis web.
