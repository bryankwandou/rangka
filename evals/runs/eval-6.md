# Eval 6 — Struktur LPJ seminar himpunan mahasiswa

Prompt: "Buat struktur laporan pertanggungjawaban acara seminar himpunan mahasiswa."

Klasifikasi: id · Genre B (Laporan, template LPJ) · pembaca: pembina/BEM/fakultas yang menyetujui dana · mode: dari nol · kedalaman: Cepat (laporan pendek), ditambah B3.

`[CEK: format LPJ dari kemahasiswaan fakultas/universitas]` — jika ada format resmi, ikuti itu dan tetap taruh ringkasan di depan jika diizinkan.

---

## 1. Peta inti

| Node | Isi |
|---|---|
| Should | Seminar berjalan sesuai proposal: target peserta, pembicara, dan anggaran `[ISI: angka dari proposal]` |
| Is | Realisasi kegiatan dan pengeluaran `[ISI: data realisasi]` |
| Gap | Selisih target vs realisasi dan anggaran vs pengeluaran, beserta penyebabnya |
| Action | Pembina menerima LPJ dan menyetujui pencairan/penutupan dana; panitia berikutnya memakai rekomendasi |

## 2. Kerangka

1. **Ringkasan** — Tugas: pembaca bisa menilai kegiatan hanya dari halaman ini. Isi: nama seminar, tanggal & tempat `[ISI]`; jumlah peserta target vs hadir `[ISI]`; anggaran rencana vs realisasi dan sisa/defisit `[ISI]`; satu kalimat capaian utama; permintaan (pengesahan LPJ / pengembalian sisa dana). Bukti: angka dari bagian 4 dan 5. Panjang: ≤1 hlm.

2. **Latar belakang & tujuan** — Tugas: mengingatkan kenapa kegiatan disetujui. Isi: latar belakang singkat dari proposal; tujuan bernomor (yang akan diukur di bagian 4); tema. Bukti: proposal `[ISI]`. Panjang: ½–1 hlm.

3. **Pelaksanaan** — Tugas: mencatat apa yang terjadi. Isi: waktu & tempat; rundown realisasi (tabel: jam rencana | jam realisasi | acara); pembicara & moderator `[ISI]`; susunan panitia; peserta. Bukti: rundown, daftar hadir. Panjang: 1–2 hlm.

4. **Capaian: target vs realisasi** — Tugas: membuktikan tujuan tercapai atau menjelaskan yang tidak.

   | Indikator | Target | Realisasi | Selisih | Keterangan |
   |---|---|---|---|---|
   | Jumlah peserta | `[ISI]` | `[ISI]` | | |
   | Pembicara hadir | `[ISI]` | `[ISI]` | | |
   | Tingkat kepuasan peserta (jika ada survei) | `[ISI]` | `[ISI]` | | |
   | Tujuan 1..n | `[ISI]` | `[ISI]` | | |

   Bukti: daftar hadir, rekap kuesioner `[ISI]`. Panjang: 1 hlm.

5. **Anggaran: rencana vs realisasi** — Tugas: pertanggungjawaban uang.

   | No | Pos | Rencana (Rp) | Realisasi (Rp) | Selisih (Rp) | Alasan selisih | No. bukti |
   |---|---|---|---|---|---|---|
   | | Pemasukan: dana fakultas/sponsor/tiket | `[ISI]` | `[ISI]` | | | |
   | | Pengeluaran: honor pembicara, konsumsi, sewa, publikasi, sertifikat, lain | `[ISI]` | `[ISI]` | | `[ISI]` | `[ISI]` |
   | | **Total / saldo akhir** | | | | | |

   Setiap selisih yang tidak nol wajib punya alasan. Hindari pos "lain-lain" tanpa rincian. Panjang: 1–2 hlm.

6. **Evaluasi** — Tugas: jujur tentang apa yang berjalan dan tidak. Isi: yang berjalan baik; kendala (mis. molor, peserta kurang) dan penyebabnya `[ISI]`; solusi saat acara. Bukti: catatan rapat evaluasi, kuesioner `[ISI]`. Panjang: 1 hlm.

7. **Rekomendasi** — Tugas: bekal panitia berikutnya. Isi: 3–5 rekomendasi, tiap rekomendasi: apa, untuk siapa (divisi/pengurus periode berikutnya), kapan. Panjang: ½ hlm.

8. **Penutup & pengesahan** — Tugas: legalitas dokumen. Isi: kalimat penutup; tanda tangan ketua panitia, ketua himpunan, pembina `[CEK: siapa yang wajib tanda tangan]`. Panjang: ½ hlm.

9. **Lampiran** — Isi: foto kegiatan, daftar hadir, nota/kuitansi (urut sesuai No. bukti di bagian 5), surat undangan pembicara, publikasi, rekap kuesioner.
