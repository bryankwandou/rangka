## Sifat pedoman: teknis, bukan isi

Pedoman UI berlaku untuk **semua fakultas, sekolah, dan vokasi**, tetapi hanya mengatur
**format**. Tiga hal penting diserahkan ke fakultas — tertulis eksplisit:

| Hal | Bunyi pedoman | Akibat bagi rangka |
|---|---|---|
| Pembagian bab | "ditentukan oleh fakultas sesuai kebutuhan" (butir 2.2) | jumlah & nama bab = `[CEK ke pedoman fakultas]` |
| Nama bab/subbab | "disesuaikan dengan kebijakan fakultas masing-masing. Misalnya, 'Tinjauan Pustaka' atau 'Tinjauan Literatur', 'Pembahasan' atau 'Analisis'" (3.13) | nama bab jangan dikunci |
| Gaya sitasi | "Setiap fakultas/departemen berhak menentukan sendiri format penulisan kutipan"; contoh yang diberikan APA dan MLA (3.17) | sitasi = `[CEK ke pedoman fakultas]` |
| Pengelompokan lampiran | "disesuaikan dengan kebijakan fakultas" (3.18) | |

**Jadi untuk UI, selalu tanyakan fakultas/prodi.** Kalau user tidak menjawab, pakai
sistematika umum yang disebut pedoman sendiri (3.13): Pendahuluan → tinjauan pustaka →
metode penelitian → hasil serta pembahasan → kesimpulan, dan tandai jumlah bab
`[CEK ke pedoman fakultas]`.

Pedoman fakultas yang diketahui ada (belum dibaca isinya): FEB UI "Pedoman Pembuatan TA"
(https://feb.ui.ac.id/pedoman-pembuatan-ta/), Teknik Industri FTUI
(https://www.ie.ui.ac.id/bagi-mahasiswa/pedoman-penulisan-tugas-akhir/). Jangan
mengutip isinya tanpa membaca.

## Format naskah (butir 3.1–3.3, 3.13–3.15)

| Aspek | Aturan UI 2017 |
|---|---|
| Kertas | HVS 80 g, putih, A4 |
| Margin | **3 cm di keempat sisi** |
| Huruf | Times New Roman 12, rata kiri-kanan |
| Spasi | 1,5 |
| Footer | "Universitas Indonesia" Arial 10 tebal, rata kanan, dari Abstrak s.d. Daftar Referensi |
| Nomor halaman | bagian awal romawi kecil (tengah bawah); isi & akhir angka Arab di **pojok kanan atas** (kiri atas untuk halaman genap cetak bolak-balik); halaman pertama bab: tengah bawah |
| Judul bab | `BAB 2` (**angka Arab**, bukan Romawi) lalu judul kapital tebal di tengah |
| Kedalaman subbab | **maksimal 3 tingkat** (`1.1`, `1.1.1`, `1.1.2.1`); rincian di bawahnya pakai huruf/bullet, tanpa sub-rincian |
| Tabel/gambar | nomor **per bab** (`Tabel 1.1`); judul tabel di atas, judul gambar di bawah; sumber TNR 10; "telah diolah kembali" bila diolah |
| Persamaan | nomor per bab `(5.1)`, rata kanan, tab 1,5 cm |
| Referensi | anjuran: **70% terbitan ≤ 2 tahun terakhir dari jurnal ilmiah internasional** |

Cetak: S1 **tidak** menyerahkan cetak ke perpustakaan, cukup unggah ke lib.ui.ac.id/unggah;
S2/S3 menyerahkan cetak bolak-balik. Ijazah diberikan hanya bila status unggahan "diterima".

## Naskah Ringkas (bab 5) — luaran wajib yang sering terlupa

Selain naskah lengkap, mahasiswa mengunggah **naskah ringkas** berformat artikel:
TNR 12 spasi 1,5, A4, margin 2,5 cm, **15–20 halaman**. Struktur: Judul · Nama penulis
(mahasiswa penulis pertama, pembimbing berikutnya, tanpa gelar) · Abstrak 150–200 kata dua
bahasa + 3–5 kata kunci urut abjad dipisah titik koma · Pendahuluan · Tinjauan Teoritis ·
Metode Penelitian · Hasil Penelitian · Pembahasan · Kesimpulan · Saran · Kepustakaan.
Masukkan ke §2b rangka sebagai lampiran/luaran `[WAJIB — unggah UI]`.

## Proposal / usulan penelitian

Pedoman UI 2017 **tidak mengatur proposal**. Struktur proposal = `[CEK ke pedoman
fakultas]`. Bawaan yang aman: bab pendahuluan + tinjauan pustaka + metode dari skripsi,
ditambah jadwal dan daftar referensi.
