# Surat Keputusan (SK) — dan bedanya dengan surat penugasan

Keluarga G. SK **menetapkan** sesuatu yang mengikat: kepengurusan, panitia, pembimbing,
AD/ART, perubahan atribut, pemberhentian/pengangkatan. SK bukan esai; bentuknya baku.

Sumber bentuk: kebiasaan tata naskah dinas di Indonesia (keputusan pejabat memakai
konsiderans *Menimbang–Mengingat* dan diktum *MEMUTUSKAN–Menetapkan–KESATU...*), yang
diatur untuk instansi pemerintah dalam pedoman tata naskah dinas — antara lain Peraturan
ANRI tentang Pedoman Umum Tata Naskah Dinas dan Permendagri tentang tata naskah dinas
di lingkungan pemerintah daerah `[CEK: nomor & tahun peraturan yang berlaku]`. Kampus
dan organisasi mahasiswa biasanya meniru pola ini lewat pedoman tata persuratan
masing-masing → **template lembaga menang** `[CEK: pedoman tata naskah kampus/organisasi]`.

## Pola SK

```
KOP              logo · nama lembaga/organisasi · institusi · alamat · kontak
                 (tanpa kop hanya bila memang internal murni dan template membolehkan)

                 KEPUTUSAN <JABATAN PENERBIT>        (atau: SURAT KEPUTUSAN ...)
                 NOMOR <nomor>
                 TENTANG
                 <OBJEK PENETAPAN, HURUF KAPITAL>

                 <JABATAN PENERBIT>,                 (diulang, diakhiri koma)

Menimbang      : a. bahwa ... ;
                 b. bahwa ... ;
                 c. bahwa berdasarkan pertimbangan sebagaimana dimaksud dalam huruf a
                    dan huruf b, perlu menetapkan Keputusan ... tentang ... ;
Mengingat      : 1. <peraturan/dokumen dasar tertinggi> ;
                 2. <statuta / peraturan akademik / kemahasiswaan> ;
                 3. <AD/ART, SK sebelumnya, nomor + tanggal> ;
Memperhatikan  : <hasil rapat/musyawarah + tanggal; rekomendasi>      (opsional)

                              MEMUTUSKAN:
Menetapkan     : KEPUTUSAN <JABATAN> TENTANG <OBJEK>.
KESATU         : <penetapan pokok; daftar nama panjang → "sebagaimana tercantum dalam
                  Lampiran yang merupakan bagian tidak terpisahkan dari Keputusan ini">
KEDUA          : <tugas, wewenang, kewajiban pihak yang ditetapkan>
KETIGA         : <masa berlaku / pembiayaan / pencabutan keputusan lama>
KEEMPAT        : Keputusan ini berlaku sejak tanggal ditetapkan, dengan ketentuan apabila
                 di kemudian hari terdapat kekeliruan akan diadakan perbaikan sebagaimana
                 mestinya.

                                     Ditetapkan di <kota>
                                     pada tanggal <tanggal>
                                     <JABATAN>,
                                     <tanda tangan + cap>
                                     <NAMA> · <NIP/NIDN/NIM bila dipakai>
Tembusan:
1. <atasan penerbit>;
2. <pihak terkait>;
3. Arsip.

LAMPIRAN KEPUTUSAN <JABATAN> NOMOR ... TANGGAL ... TENTANG ...
  <tabel: No · Nama · NIM/NIP · Jabatan dalam kepanitiaan/kepengurusan>
  <tanda tangan penerbit diulang di akhir lampiran>
```

## Aturan bentuk

| Aturan | Keterangan |
|---|---|
| **Menimbang = alasan** | huruf kecil `a. b. c.`; tiap butir diawali `bahwa`, diakhiri `;`; butir terakhir merangkum: "... perlu menetapkan ..." |
| **Mengingat = dasar hukum/dokumen** | angka `1. 2. 3.`; urut dari yang **tertinggi**; tiap dokumen dengan nomor + tahun/tanggal atau `[ISI]`. Mencampur alasan ke Mengingat (atau dasar hukum ke Menimbang) adalah kesalahan paling umum |
| **Memperhatikan** | opsional; untuk hasil rapat, usulan, rekomendasi — bukan peraturan |
| **Diktum** | kata bilangan tingkat kapital: `KESATU, KEDUA, KETIGA, ...` (pola naskah dinas pemerintah). Sebagian template organisasi memakai `PERTAMA` atau `Pasal 1` — ikuti template lembaga, tapi **jangan mencampur** dalam satu SK |
| **Klausul berlaku + ralat** | diktum terakhir: sejak kapan berlaku + perbaikan bila ada kekeliruan |
| **Nomor** | mengikuti kode klasifikasi lembaga. Pola umum `<urut>/<kode unit>/<kode jenis>/<bulan Romawi>/<tahun>`, tetapi **tidak semua lembaga memakai bulan** — contoh nyata di FTI UAJM: `006/FTI/SK/Kajur TI/KP/2026` (urut/fakultas/jenis/penerbit/kegiatan/tahun). Rangka **tidak mengarang nomor**: `[ISI: nomor dari sekretariat]`, dan menyebut pola lembaga bila user memberi contoh |
| **Lampiran** | daftar nama panjang tidak masuk diktum; lampiran diberi kepala yang menyebut nomor & tanggal SK, dan ditandatangani ulang |
| **Tembusan** | untuk atasan dan pihak yang harus tahu; bukan untuk pihak yang ditetapkan |
| **Batas keanggotaan** | sebutkan siapa yang **tidak** termasuk bila relevan (mis. anggota biasa tidak dicantumkan di SK kepengurusan) |

## SK vs surat penugasan vs surat pengantar SK

Tiga dokumen yang sering tertukar. Pola yang teramati pada dokumen nyata FTI UAJM
(penugasan dosen pembimbing kegiatan mahasiswa, 2026):

| Dokumen | Bentuk | Kapan dipakai |
|---|---|---|
| **Surat Keputusan** | konsiderans Menimbang/Mengingat + MEMUTUSKAN + diktum | menetapkan status/aturan yang berlaku umum atau jangka panjang |
| **Surat Penugasan / Surat Tugas** | judul `SURAT PENUGASAN` + nomor · `Dari :` · `Kepada :` · `Isi :` 1. tugas (+ identitas pihak terkait dalam tabel kecil Nama/Stambuk/Lokasi) 2. "agar dilaksanakan dengan penuh tanggung jawab" · tempat-tanggal · jabatan, tanda tangan, cap · `Tembusan` | menugaskan orang tertentu untuk tugas tertentu; **tanpa** Menimbang/Mengingat |
| **Surat pengantar (penyampaian SK)** | kop · `Nomor` · `Lamp.` · `Hal` · `Kepada Yth.` · `di- Tempat` · `Dengan hormat,` · isi 1–2 paragraf merujuk nomor SK/surat penugasan · penutup "Demikian ... terima kasih" · tempat-tanggal · jabatan · `Tembusan` | mengirimkan SK/surat penugasan ke pihak yang dituju |

Kalau user meminta "SK" tetapi isinya hanya menugaskan satu orang untuk satu kegiatan,
tanyakan (sebagai satu-satunya pertanyaan) atau nyatakan asumsi: apakah lembaganya memakai
**surat penugasan** untuk itu. Jangan menyulap surat penugasan menjadi SK berkonsiderans.

## Peta inti

| Node | Isi |
|---|---|
| Should | organisasi/kegiatan berjalan dengan dasar yang sah |
| Is | belum ada penetapan resmi / penetapan lama tidak berlaku |
| Gap | kekosongan dasar hukum |
| Reader | pihak yang ditetapkan + pihak luar yang memeriksa keabsahan |
| Core claim | sejak tanggal ini, hal berikut berlaku |
| Proof | konsiderans + dokumen dasar yang dirujuk |
| Action | melaksanakan diktum |

## Cek SK (SK)

| Kode | Cek |
|---|---|
| SK1 | Menimbang berisi alasan (`bahwa ...;`), Mengingat berisi dasar hukum urut dari tertinggi — tidak tertukar? |
| SK2 | Butir terakhir Menimbang = "perlu menetapkan ..."? |
| SK3 | Diktum memakai satu pola (KESATU... atau pola template) konsisten, ada klausul berlaku + ralat? |
| SK4 | Ditetapkan di / pada tanggal / jabatan / nama penanda tangan ada? |
| SK5 | Nomor tidak dikarang; pola nomor mengikuti lembaga atau `[ISI]`? |
| SK6 | Daftar nama panjang di Lampiran, lampiran berkepala nomor-tanggal SK? |
| SK7 | Jenis dokumen tepat (SK vs surat penugasan vs surat pengantar)? |
| SK8 | Setiap dokumen di Mengingat punya nomor & tahun atau `[ISI]`/`[CEK]`, tidak ada peraturan karangan? |
